> 不会写代码，也能带着你的 Agent 做出能用的产品。

## 你是谁（入门自测 · 定入口站）

- 用过终端、敲过命令吗？没用过 → 从 **A1** 开始
- 会用 git 提交代码吗？会 → 可跳过 A1，从 **A2** 进
- 写过 Python、能读懂函数与类吗？能 → **A3** 可快速略过，但仍建议做 **A4**（读懂后端）拿本阶段徽章
- 调用过大模型 API（写过一次请求）吗？调过 → **B1** 可快速过
- 有后端开发经验、但没用过指挥式 Agent？→ 建议改走 **engineer-transform**；想留在本路径就从 **C1** 进（跳过 A/B）
- 日常已在用 Cursor / Claude Code 干活？是 → 改走 **engineer-transform** 路径

**这条路不适合谁（给出口，不关门）**
- 已有开发经验的工程师 → 改走 engineer-transform；只想快速补 Agent 用法可留在本路径但从 C1 进
- 有后端经验、没用过指挥式 Agent → 优先 engineer-transform；想低成本试水则从 C1 进
- 只想听原理、不想动手交产出 → 本路径每站都要交产出物；想纯理论先看加餐篇再回来

## 节奏三档（不改路线，只改快慢）

| 档位 | 每周投入 | 大约周数 | 适合 |
|---|---|---|---|
| 稳扎 | 6h/周 | ~11 周 | 在职、每周只挤得出 6 小时 |
| **推荐** | 10h/周 | ~7 周 | 业余投入的主力节奏（下面「你会拿到什么」的工时区间按此档估） |
| 全职冲刺 | 35h/周 | ~2 周 | 全职脱产 |

> 工时均为经验估算，因人而异，不作为固定周数的承诺。

## 你会拿到什么（留余量口径）

**外部准备提前一站预告（提前准备已上移）**

- C2 预告：C3 要用的 **阿里云百炼 DashScope Key**（约 10 分钟）
- E1：复用 B1 的 DeepSeek Key，无需新申请

**B1 最低硬件规格 & 降级线**
- 本地跑 1.5B：建议 ≥16G 内存；有 NVIDIA 显卡（≥6G 显存）更顺；Apple Silicon（M1+）可跑；≥5G 磁盘

## 双通道怎么走（快车道 / 深潜道）

- **A/B 阶段（全家桶未装）**：用**基座 Agent 轻快车道**——Cursor / Claude Code 本体带你做，不依赖课程包；每条轻快车道都带原理回链（想懂就回看对应讲次）。
- **C3 起（全家桶已装）**：开启**课程包快车道**，装对应能力包，让 Agent 按课堂工程方法带做；产出后顺着原理回链回看原理。
- **深潜道**：看课件、懂原理、自己实现。**徽章只认深潜专属到站验收**，快车道拿产出，深潜道拿徽章，原理不可跳过。

## 单节点实操超过 4 小时的已拆成两道子验收
- **A3**（手写笔记 → 读函数与类）、**C3**（Cursor Rules 生效 → MCP 连通）、**D1**（边界+description 定稿 → 触发测试通过）各设两道子验收，避免一次性大验收卡壳。

## 复习锚点（对抗遗忘）
每站技能在后续会被复检，例如：A1 git → C1/E1；A3 Python → A4/D1/E1；B1 API/token → C3/E1；C2 全家桶 → C3/D1/E1；C3 MCP → E1/E2；D1 Skill → D2/engineer-transform。

- **并轨点**：到 E 阶段可并入 **engineer-transform**，起点即工程师转型路径 Stage 4（Agent 开发框架）。

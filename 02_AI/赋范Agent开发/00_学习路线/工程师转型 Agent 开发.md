# 工程师转型 Agent 开发 · 人读版

> 你已经会写代码，这条路把你从「会编程」带到「能独立造 Agent 并让它上线」。
> 路径 id：`engineer-transform`　推荐节奏：10h/周 × 10 周（工时为区间估算，非硬承诺）

---

## 这条路适合谁

- **适合**：有编程基础、但没系统做过 AI/Agent 开发的工程师（后端/全栈/算法转型者）。也承接 `zero-to-builder` 的毕业生，他们从本路径 A 阶段并入。
- **不适合（都给了出口）**：
  - 零编程基础的新手 → 改走 `zero-to-builder`，练完全栈与基座再回来
  - 只想低代码搭一个不碰源码的 Agent → 改走低代码支线（Stage 4「01_基础开发框架」低代码实战）
  - 只想做 RAG 知识库、不做通用 Agent → 可直接从 E 阶段知识库项目组切入，跳过 B/C 的通用框架深走

### 入口自测（决定你从哪一站进）

- 从没调用过大模型 API、没写过 prompt 工程 → 先走 zero-to-builder 的模型与基座段，再回本路径 **A1**
- 没用过 Claude Code / Cursor 指挥 Agent → 从 **A1** 开始，基座速通不能跳
- 读得懂 think-act-observe 循环、能手写最小 ReAct → **A1/A2** 快速过，重心从 **B2** 起步
- 已在生产环境部署过 Agent 服务 → 可从 **D** 阶段切入，把 A/B/C 当查漏复习

## 快车道 / 深潜道怎么用

- **快车道**：装对应能力包 → 让 Agent 带着做 → 快速拿产出。每个快车道都带**原理回链**回到课件讲次，想知道「为什么」随时回看。
- **深潜道**：看课件懂原理、自己实现。每阶段徽章闸门都在深潜专属到站验收上，快车道刷不出徽章。
- **前期站的例外**：A1/A2 在 A3 装全家桶之前，快车道用「基座 Agent 轻带」（Claude Code/Codex 本体陪读，不挂课程包）；cc-arch-pack、codex-workflow-pack 在 A3 装好后回看时启用。
- **手搓站的例外**：B3、E1 的深潜徽章要求「自己手写」，快车道仅用于看一个可运行参照或代做部署，**核心产物（手搓 loop / 改造 diff）必须自己写**。

# 冲高薪就业 · 人读版（career-sprint）

> 全主线精编：从大模型基础一路打到 4 个企业级系统 + 微调实战，攒一份能过技术面的作品集。
> 面向以求职/跳槽为目标的你，支持「从零基础」「会码不会 AI」两档入口。
>
> 平台正式上线前，这份文档就是你的完整地图：**阶段序列表 = 地铁图**、**到站验收勾选清单 = 进度条**、**阶段里程碑达成声明 = 徽章**。

## 你适合走这条吗

- **适合**：应届/转行想进 AI 岗、想从普通开发跳到 Agent/大模型方向、需要一份能扛技术面的工业级作品集。
- **不适合（给你指路，不关门）**：
  - 已在做 AI 工程、只差项目背书的资深工程师 → 直接从 E 阶段旗舰项目切入，或走 engineer-transform 进阶档。
  - 只想在职提效、不打算求职 → 改走 **zero-to-builder（零基础超级个体）**，投入更轻。
  - 想先看完全部原理再动手、抗拒每站交产出 → 本路径每阶段都有深潜关卡，按半脱产/全职冲刺档才跟得上。

## 入口自测（用站号定起点）

1. 从没调用过大模型 API、也没做过任何部署？→ 从 **A1** 起步（零基础档，A1–A7 全走）
2. 会写 Python，但没碰过大模型 API / 本地部署？→ A1 快速过，力气花在 **A3–A7**
3. 已能独立调用大模型 API，且用过 Cursor / Claude Code？→ 直接从 **A5** 进（跳过 A1–A4，会码档）
4. 已是资深 Agent 工程师，只想要项目背书？→ 直接进 **E 阶段**，基础与微调按需回补
5. 只想在职提效、不打算求职？→ 改走 **zero-to-builder**

## 三档节奏（投入与周数对得上）

| 档位 | 每周投入 | 周数 | 说明 |
|---|---|---|---|
| 在职稳扎 | 12h | 18 周 | 工作日晚 + 周末，徽章关卡不打折 |
| 半脱产推荐 ★ | 18h | 11 周 | 推荐节奏，11 周产出全套作品集 |
| 全职冲刺 | 34h | 6 周 | 脱产求职冲刺，需连做项目不掉链子 |

> 总实操量约 **205h**，为经验估算、因人而异；推荐按「半脱产」档规划节奏。

## 承诺（留余量口径）

按半脱产推荐节奏（约 11 周），你可以产出一套求职级作品：**4 个企业级系统**（编译式 RAG 知识工厂 / AI 客服中台 / OPC 数字员工工厂 / 工业级数据分析智能体，各附约 8h 工时区间）+ 一份能写进简历的**微调实战记录**（LoRA/QLoRA 全流程，含显存账与领域指标）。不同基础与投入档位工时会浮动，作品清单不变——写「按节奏可产出」，不承诺「N 周必得」。

# 选择你的学习路径

> 同一套课程，五条走法。先花 2 分钟对号入座，再按你那条路径的人读版逐站走——
> 每一站都写清：看什么、装什么、做什么、到站标志是什么。

## 两问定路

**第一问：你现在会什么？**
**第二问：你学完要拿到什么？**

| 你是谁 | 走这条 | 走完手里有什么 |
|---|---|---|
| 没有编程基础，想做出自己的东西 | **零基础超级个体**（5 阶段 12 站） | 4 样能演示的作品：ChatGPT 克隆、NL2SQL 助理、自己的 Skill、一句话部署的数字员工 |
| 会编程，想转 Agent 开发 | **工程师转型 Agent 开发**（5 阶段 16 站） | 工业级 Agent 系统能力 + 复刻级项目 |
| 产品/业务岗，不以写码为业 | **产品/业务岗 AI 全栈**（4 阶段 10 站） | 一份生产级 PRD + 自己主导的 MVP + 两个部署跑通的项目 |
| 求职跳槽，冲高薪 | **冲高薪就业**（5 阶段 29 站） | 简历口径的 4 大企业级系统 + 微调实战记录 |
| 老板/独立开发，要业务落地 | **企业落地/一人公司**（4 阶段 10 站） | 一个业务场景生产可用 + 可复制到第二场景的方法 |

拿不准就打开对应人读版看开头的「反画像 + 入门自测」——每条路径都写明了谁不该走它、该改走哪条、以及按你的基础该从第几站进。

## 每条路径的用法

1. 打开本文件夹里对应的「·人读版」文档
2. 按阶段顺序走，每站四件事：**看**（课件）→ **装**（能力包）→ **做**（项目/练习）→ **验**（到站标志）
3. 大多数站有两条通道：**快车道**（让装了课程技能包的 Agent 带你直接做出产出）和**深潜道**（看课学原理自己实现）——快车道拿产出，深潜道拿阶段徽章，两条都通向同一个验收
4. 每站的「下一站预告」会提前告诉你要申请什么 Key、下什么模型——先备料再开学，别让申请审批打断学习

## 说明

- 路径里的每个引用（课件/技能包/项目/资料）都在本套课程资料里，照着走不需要课程之外的任何资源
- 时长为经验估算，因人而异；标「随课解锁」的站会按课程进度陆续放出
- 走完任何一条路径，文档末尾的「毕业后去哪」会告诉你可以并入哪条进阶路径

# Agent 从0开始 课程 FAQ

## 一、入门基础

**Q：纯小白能学吗？**
能。定位就是从 0 开始，不需要编程基础。但最好有个明确想做的事（比如用 AI 帮忙写文案、做数据分析、自动化办公），不然容易学着学着失去方向。

**Q：需要编程基础吗？**
不需要。主要操作是点点点和看效果，不强制写代码。

**Q：电脑配置有什么要求？**
普通笔记本/台式机即可，课程主要使用云端 API，不强制要求高配置。

**Q：安装复杂吗？需要多久？**
课程手把手带安装，从下载到跑起来第一步。基础安装 30 分钟内可以完成。

**Q：国内网络能正常使用吗？**
可以。课程会提供国内可用的替代方案，不存在访问障碍。

**Q：Mac/Windows 系统都支持吗？**
主要以 Windows 为主（建议 Windows 11），Mac 部分内容通用。买之前可以先看现有免费内容确认兼容性。

## 二、内容与课程体系

**Q：599 包含哪些内容？**
一年知识星球会员 + 答疑群 + 不定期直播 + 交流分享会 + 全部课程内容（当前 30 篇+ 持续更新，每周至少 4 篇）。

**Q：课程大纲是什么？**
覆盖：安装 → Skill 资源 → Agent 基础能力 → 定制 Agent。从"装起来"到"用起来"，从零开始搭建自己的 Agent 工作流。

**Q：已经有 30 篇了，内容够吗？**
够了，但还在持续增加。每周至少 4 篇，涵盖安装、Skill 资源、基础能力、定制Agent。不定期还有加餐。

**Q：主要讲哪些 Agent？**
开源工具：OpenClaw、Hermes；通用产品：QClaw、WorkBuddy 等。主流工具都有涉及，以"用起来"为导向，不炫技。

**Q：和其他 AI 课有什么区别？**
不卖焦虑课，主打"和你一起用起来 AI Agent"。不是让你花钱学完还是不会，是真的手把手带跑起来。工具选型实用导向，不推贵的。

**Q：学完能达到什么水平？**
能独立搭建自己的 Agent 工作流，解决实际问题（比如自动写文案、数据整理、客服机器人），而不是只会跟教程操作。

**Q：有没有课程目录可以先看看？**
有。可以先看知识星球内现有免费内容，确认风格是否适合你。

**Q：内容是视频还是图文？**
图文为主（更适合检索和收藏），直播会录像回放。

**Q：后续会有新工具加入吗？**
会。主流工具持续跟进，不定期加餐，保持更新。

**Q：课程内容和答疑群有地域限制吗？**
无。只要能上网就能用，不受地域限制。

## 三、服务与答疑

**Q：答疑群怎么用？**
付费后邀请进群，可以直接提问。群内即时回答 + 定期汇总（常见问题整理成帖）。

**Q：提问后多久回答？**
工作日内尽量 24 小时内回复。

**Q：有直播吗？多久一次？**
有，不定期直播。主题可能是加餐内容、答疑或案例演示，具体看星球内通知。

**Q：交流分享会是什么形式？**
群内或线上，主题分享 + 自由交流，具体看通知。

**Q：错过直播怎么办？**
直播结束后会整理回放/笔记，发在星球内，随时可看。

**Q：内容更新通知怎么收到？**
知识星球 APP 会推送，也可以设置微信提醒。

## 五、实操问题

**Q：遇到报错怎么办？**
先在星球内搜索是否有同类问题；没有的话发到答疑群，尽量描述清楚：环境 + 操作步骤 + 报错截图。

**Q：API Key 怎么申请？**
课程会详细讲，覆盖国内外常见渠道，附国内可用的替代方案。

**Q：OpenClaw / Hermes / QClaw / WorkBuddy 有什么区别？**
各有侧重：OpenClaw 和 Hermes 是开源工具，QClaw 和 WorkBuddy 是通用产品。课程会根据场景推荐，不强行对比。

**Q：OpenClaw 和 Hermes 哪个更适合新手？**
两个都会讲，根据你的需求来选。课程会手把手带安装，不用纠结先学哪个。

**Q：课程需要额外付费购买工具吗？**
不需要。课程内容本身已包含在 599 年费里，工具本身有免费版和付费版，按需选择，不强制消费。

**Q：课程内容可以下载吗？**
知识星球内支持收藏和缓存，具体以平台功能为准。

**Q：课程结束后还能看吗？**
有效期一年，期间内容都可以反复看。过期后如续费可继续查看。
